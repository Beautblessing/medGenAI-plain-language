# medGenAI 4.1

Local Gradio research prototype for governed English–Spanish clinical-reference
review, exact-text narrative approval/freeze, and reproducible plain-language
NLP evaluation using a 10-case fictional dataset.

The authoritative step-by-step reproduction guide is [readme.txt](readme.txt).
Before running anything, read the privacy/publication boundary and verify
`PUBLIC_DATA_SHA256SUMS`. No real patient data should be used.

Submission status and the verified public URL (when available) are recorded in
[repository_submission.md](repository_submission.md).
